# Figure guide

The figures are grouped by their role in the study:

- `setup`: laboratory photographs supplied with the experiment record;
- `method`: waveform, integration-gate, and scintillator-method illustrations;
- `results`: accepted breakdown-voltage and repeatability results;
- `diagnostics`: trigger, lower-bias, acquisition, and model-limit checks.

Plot files are derived from the processed data and analysis scripts in this repository or from the corresponding raw campaign listed in `data/raw_data_index.csv`. A diagnostic figure should not be interpreted as an accepted calibration result unless the results document says so.

The setup photographs were resized for practical repository use. The original full-resolution files remain in the local experiment archive.
